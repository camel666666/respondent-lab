# Security policy

Please do not publish API keys, raw personal histories, interview transcripts, or identifiable response data in an issue or pull request.

If you find a security or privacy issue, use GitHub's private vulnerability reporting feature when available. Otherwise open an issue with only a non-sensitive summary and ask maintainers for a private channel.

The demo is designed to run offline. Paid model calls require an explicit provider selection and an API key supplied through the environment. Users who import real-person-derived profiles are responsible for consent, minimization, access control, retention, and deletion in their deployment. The repository intentionally does not host those profiles.
